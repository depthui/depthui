# Security Policy

Depth UI is a front-end source library with no server component. If you find a vulnerability in the code (for
example an XSS risk in a component), please report it privately.

**Do not open a public issue.** Use GitHub's
[private vulnerability reporting](https://github.com/depthui/depthui/security/advisories/new) for this repository.

Please include steps to reproduce and the affected component. We aim to reply within a few days and to ship a fix
promptly. Only the latest version on `main` is supported.
